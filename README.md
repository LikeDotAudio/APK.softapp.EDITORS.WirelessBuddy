# EDITORS.WirelessBuddy — Wireless RF Spectrum Buddy

**Wiki:** [Documentation/README.md](Documentation/README.md) — principles, architecture, delivery.

Wireless RF Spectrum Buddy: UHF wireless microphone frequency coordination, 3rd and 5th-order intermodulation distortion (IMD) avoidance, TV channel white space clearance, and antenna distribution calculations.

| | |
|---|---|
| **Opens** | the OS shell (Design → Wireless & RF), or `index.html` standalone |
| **Build** | none — plain web files; `npm test` |
| **Ships** | baked into WEB.Frontend-Assets (`up-stack.sh WEB.Frontend-Assets`), served at `:8080/Softapps/EDITORS/EDITORS.WirelessBuddy/` |
